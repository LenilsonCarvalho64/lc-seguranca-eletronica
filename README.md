# LC Segurança Eletrônica — Landing Page

Landing page institucional da **LC Segurança Eletrônica**, com foco em atendimento residencial e comercial em Barras-PI e região.

## Recursos

- CFTV, alarmes, cercas elétricas, controle de acesso e automação
- Instalação e manutenção
- Formulário que envia os dados diretamente para o WhatsApp
- Botão flutuante do WhatsApp
- Layout responsivo para celular e computador
- SEO local para Barras-PI e região
- `robots.txt` e `sitemap.xml`
- Configuração pronta para Vercel

## Como editar

Abra este repositório no VS Code, edite `index.html`, `styles.css` e `script.js`, salve e envie as alterações para o GitHub.

Quando o repositório estiver conectado à Vercel, cada atualização enviada para a branch `main` poderá gerar uma nova publicação automaticamente.
