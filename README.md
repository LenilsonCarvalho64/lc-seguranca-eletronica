# LC Segurança Eletrônica — versão editável

Projeto estático em HTML, CSS e JavaScript, pronto para abrir no VS Code.

## Estrutura
- `index.html` — conteúdo e estrutura da página
- `styles.css` — toda a estilização e responsividade
- `script.js` — menu mobile, WhatsApp, formulário, animações e galeria
- `assets/` — logo e fotos reais em WebP
- `vercel.json` — configuração da Vercel
- `robots.txt` e `sitemap.xml` — SEO básico

## Editar localmente
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Use a extensão Live Server ou abra `index.html` no navegador.
4. Edite HTML/CSS/JS e salve.

## Publicar
Como o projeto da Vercel está conectado ao GitHub, basta substituir/atualizar os arquivos no repositório `LenilsonCarvalho64/lc-seguranca-eletronica` e fazer commit/push na branch `main`.
